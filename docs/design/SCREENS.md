# Pax Pixelia — экраны (v1)

Спецификации и каркасы следующих экранов в стиле «Мрамор и графит». Всё, что уже сделано в волне 1 (верхняя панель, лист провинции, миникарта, полоса режимов, лента событий, таблица лидеров), остаётся точкой отсчёта. Новые экраны расширяют их, а не заменяют. Макеты ASCII условные: пропорции и точные отступы берём из `docs/mockups/main_screen.html` и `UI/Theme`.

Коды идей (U-, T-, S-…) ведут в [IDEAS.md](../IDEAS.md), вопросы — в [OPEN_QUESTIONS.md](../OPEN_QUESTIONS.md).

## 0. Язык «Мрамор и графит»

**Токены** (`UI/Theme/Pal.cs`, `style.css`)

| Токен | Значение | Где |
|---|---|---|
| `P1` | `#F9FAFB`, α 0,965 | карточка и лист поверх карты |
| `P2` / `P3` | `#FFFFFF` / `#EFF1F3` | приподнятая строка / утопленная ячейка, плитка иконки |
| `Hd1→Hd2` | `#FDFDFE → #F0F2F4` | градиент шапки листа |
| `Ln` / `Ln2` / `Ln3` | `#E1E4E8` / `#C4CAD0` / `#959DA6` | линия внутри карточки / контур / hover |
| `Tx` / `Tx2` / `Mu` / `Mu2` | `#1D2126` / `#434A52` / `#646C76` / `#9BA2AA` | текст / иконки / вторичный / бледный |
| `G1`…`G2` | `#3A4048 … #2A2F35` | графитовая заливка: главная кнопка, «изучено» |
| `Ok` / `Bad` / `Warn` / `Sci` | `#2D7A3C` / `#B3392B` / `#9A620C` / `#46627F` | смысловые цвета: дельты, тревоги, ссылки-понятия |
| Тень | `0 1px 2px rgba(16,20,26,.14), 0 12px 30px -8px rgba(16,20,26,.40)` | карточки и листы |
| Радиус | 4–6 px | — |

**Шрифты**
- Alegreya SC 500/700/800: заголовки, даты, названия на карте, не мельче 15 px.
- Fira Sans Condensed 400/500/600: интерфейс и числа. Для чисел всегда `tnum` + `lnum` (`FontVariation.OpenTypeFeatures`).

**Правила**
1. **Цвет только у данных:** державы, классы, веры, фракции, дельты. Всё остальное — графит.
2. **Любое число объясняется одним наведением.** Пример: «Налоги +18 · Содержание −6 = +12 за УГ».
3. **Цвет всегда вместе со знаком** ▲▼ или узором: так читают и дальтоники.
4. **Срок показывается дважды:** игровой датой и реальным временем «≈3 мин на x3». На паузе вместо реального времени — «на паузе».
5. **Пиксель-арт** (флаги, портреты, иллюстрации) масштабируется только целым числом, фильтр nearest.
6. **Анимация:** въезд листа на 8 px за 140 мс ease-out. При «меньше анимации» въезда нет.

**Кит** (расширяем существующий `UI/Widgets/Kit.cs`, второй не пишем): `Ui.Card`, `Ui.H4(title, aside)`, `Ui.Stat(cap, val)`, `Ui.Grid2`, `Ui.Row(icon, text, meta, btn)`, `Ui.Chip`, `Ui.Tag`, `Ui.Prog`, `Ui.Pips5`, `Ui.Kv`, `Ui.Kbd`, `Ui.Own`, `Fmt.Num` («12 400», «12,4 тыс.», «3,1 млн», узкий неразрывный пробел U+202F). Страница-витрина всех компонентов участвует в скриншот-тесте.

## 1. Каркас: листы поверх живой карты (U-1)

```
┌─ верхняя панель 54 px (всегда) ─────────────────────────────────────────────────────┐
│ [флаг] Ардания · Вождество │ Казна Наука Нас. Стаб. Вл. │ T P M D R N L [кубок] │ [||] Осень 1142 ▮▮▮ ⌛2:14 │
├─────────────────────────────────────────────────────────────────────────────────────┤
│                     [! 2][* 1][= 1][+]  ← строка тревог (T-2)      Скоро: ▸ Ферма 0:18 │
│ ┌события─364┐                               ┌──────── лист M · 720 px ────────────┐ │
│ │ заметки P3 │     КАРТА: линза листа        │▌Религия   [Гонка][Основать][Мир]   × │ │
│ │ «Путь      │     (цветная, живая,          │  …                                  │ │
│ │  вождя»    │      подсветка провинций      │                                     │ │
│ └────────────┘      из строк листа)          │                                     │ │
│ [полоса режимов]                             └─────────────────────────────────────┘ │
│ [миникарта]                                                                           │
└─────────────────────────────────────────────────────────────────────────────────────┘
```

| Размер | Ширина | Экраны |
|---|---|---|
| **S** | 360 px | Провинция (уже есть), карточка правителя |
| **M** | 720 px | Религия, Политика, Народ, Дипломатия, Настройки, Сделка, Кодекс |
| **L** | ширина − 12 − 376 − 12 (1520 px при 1920) | Технологии, Рынок, Летопись |

- **Всегда видны:** верхняя панель, строка тревог, часы, колонка событий и миникарта. Одновременно открыт не больше 1 листа M или L и 1 листа S; при открытом M/L лист провинции встаёт слева от него. Ниже 1600 px лист S сворачивается во вкладку на краю. На 1280×720 лист L занимает весь экран, а колонка событий сворачивается в значки.
- **Линза.** Лист при открытии включает свой режим карты через `Game.I.PushLens(mode)` и возвращает прежний при закрытии (`PopLens`):
  - Религия → «Религии»;
  - Рынок → «Торговля»;
  - Политика → «Недовольство»;
  - Народ → «Классы»;
  - Дипломатия → «Отношения».
- **Подсветка в обе стороны:** наводишь на строку листа — `Game.I.HighlightProvinces(ids, pulse)` обводит провинции 1 px белым + 1 px графитом; кликаешь провинцию — лист фильтруется по ней.
- **Ввод.** Колесо над листом крутит лист, а не карту. Клик в пустую карту лист не закрывает. Лист перехватывает мышь, чтобы не конфликтовать с `MapCamera`.
- **Шапка:** Alegreya SC 23, под ней полоса цвета державы 3 px. Первая вкладка каждого листа — «Сводка» с 4–6 главными числами.
- **Клавиши:** Esc закрывает верхний лист, повторная горячая клавиша тоже закрывает, Ctrl+Tab переключает два последних листа.
- **Реализация:** `UI/Sheets/Sheet.cs : PanelContainer` с полями `Size`, `Lens`, `Hotkey`, `Title`, `Tabs` и методами `Build()` / `Refresh()`. Подписка на `Game.I` в `_EnterTree`, отписка в `_ExitTree`. `SheetHost` в `Hud`.

### 1.1 Превью последствий на карте (U-6)

При наведении на действие карта на время окрашивается прогнозом по провинциям:
- **постройка** — где её можно поставить и примерный выпуск;
- **технология** — где откроются здания и ресурсы (для «Ирригации» загораются степи у рек);
- **закон** (M2) — изменение настроения, расходящаяся шкала и штриховка ▲▼;
- **святое место** — радиус давления;
- **договор** (M2) — линия будущего пути.

`Game.I.ShowOverlay(int[] perProvince, style)`. Появляется через 120 мс, гаснет за 150 мс, текущая линза в это время приглушена до 40%. Предсказатели `Sim/Predict/*` вызывают те же функции правил в режиме чтения, команд не создают.

## 2. Уведомления, строка тревог, лента «Скоро» (T-1, T-2)

```
  верхняя панель ─────────────────────────────────────────────
          ┃* 1┃ ┃$ −3 УГ┃ ┃= 2┃ ┃+ !┃  +2          Скоро ─────────────
           sci    bad     warn  ok               ▸ Ферма, Вельдор   0:18
                                                 ▸ Бронза (слот 1)  2:40
 ┌события P3┐              ┌решения P1 (стопка)┐ ▸ Замысел «Пять…» 11:05
```

| Уровень | Вид | Поведение |
|---|---|---|
| **P0 Кризис** | карточка по центру + звук | отделение города, чужая вера основана у нас, рассинхрон. В одиночной игре автопауза, в сети без неё |
| **P1 Решение** | стопка карточек под строкой тревог (§11) | событие с выбором, сделка |
| **P2 Тревога** | значок 28 px со счётчиком и цветной полосой слева | живёт, пока держится условие; исчезает сам |
| **P3 Сведение** | заметка в левой колонке | 8 с, потом уходит в летопись; одинаковые за 10 с склеиваются («Засуха ×3») |

- **Примеры тревог:**
  - свободный слот науки;
  - казна уйдёт в минус через N УГ;
  - безработица больше 10% в N провинциях;
  - можно основать веру;
  - разведчик без дела;
  - очередь стройки пуста;
  - ступень недовольства.
- **Строка тревог.** Видно до 8 значков, остальное — «+N». Если курсор далеко, строка полупрозрачна (70%). Тост опускается на 104 px, чтобы не спорить со строкой.
- **Управление:**
  - клик — к причине, повторный клик — следующий случай;
  - правый клик — скрыть на 10 УГ;
  - Ctrl+клик — настройки типа: показывать / звук / автопауза (одиночная) / в летопись;
  - `.` — следующая тревога, Shift+`.` — предыдущая;
  - в тултипе тревоги есть «как исправить» со ссылками-понятиями.
- **Лента «Скоро»:** 3–5 ближайших завершений с обратным отсчётом в реальных секундах, клик ведёт к провинции.
- **Данные:** `Sim/Alerts.Evaluate(w, s, nation)` и `Sim.Upcoming(nation)` — чистые функции. `ISimSink.Notify(nation, type, priority, key, args, province)`; старая сигнатура остаётся обёрткой.

## 3. Гиперподсказки и Кодекс (U-2)

```
┌ СТАБИЛЬНОСТЬ ───────────────── 62 ┐   ┌ Стабильность › Мысли ─────────────┐
│ Среднее настроение попов          │   │ МЫСЛИ ОБЩИННИКОВ (Вельдор)        │
│ Общинники  ▓▓▓▓▓▓░░  58           │──▶│ Хлеб подорожал            −6      │
│ Жрецы      ▓▓▓▓▓▓▓░  71           │   │ Новый храм                +4      │
│ ⋯ см. [мысли] · [уровень жизни]   │   │ Подать высока             −4      │
│ ▂▂▂▂▂▂▂▂▂▂▂ (закрепление 0,6 с)   │   │ прочее                    ±3      │
└───────────────────────────────────┘   └───────────────────────────────────┘
```

- **Понятия** (Стабильность, Влияние, Общинники, Догмат, Эврика…) выделены цветом `Sci` с точечным подчёркиванием. Наведение открывает следующую подсказку, глубина до 4 уровней, над ними «хлебные крошки».
- **Закрепление:**
  - по таймеру 0,6 с, в углу заполняется полоска (время 0,3–1,5 с настраивается);
  - Ctrl — мгновенно;
  - средней кнопкой мыши (вариант в настройках).
- **Прикалывание:** Shift+клик прикалывает карточку. Не больше 3 карточек, они стоят столбиком под колонкой событий.
- **Тайминги:**
  - открытие 350 мс; если подсказка была меньше 500 мс назад — сразу;
  - закрытие через 250 мс;
  - внутри «безопасного треугольника» от курсора к дочерней карточке подсказка не закрывается.
- **Позиция:** корневая — +16 px вправо-вниз от курсора, у края экрана отражается. Дочерняя — от прямоугольника ссылки.
- **Кодекс (F1)** открывается листом M на понятии под курсором. Разделы, поиск, ссылки.
- **Данные:** `Core/Concepts` (JSON): id, заголовок, текст до 240 символов в BBCode со ссылками `[url=c:stability]`, иконка, связанные понятия. Текст подсказки строится лениво, числа обновляются не чаще 4 раз в секунду.
- **Реализация:** своя `TipCard` на `CanvasLayer 90`. Встроенный `tooltip_text` не пускает внутрь мышь, а у нынешнего `Tooltip.cs` стоит `MouseFilter = Ignore`.
- **Тест:** каждая ссылка `[url=c:x]` ведёт на существующее понятие.

## 4. Технологии — «Партитура эпох» · лист L · T · M1 (A-2, A-3)

```
┌ Технологии ─────────────────────────────────────────────── [Обзор Z] [Поиск F] ×┐
│ СЛОТЫ [1 Ирригация ▓▓▓▓░░ 62% · 812 до н.э. · ≈3 мин][2 Бронза ▓▓░░ ≈5 мин][+ свободен] │
│       очередь: Севооборот › Гончарный круг                                          │
│ ЭПОХИ  Первоб. ✓ │ Древний мир ■■■■■■■□□ 7/15 до смены │ Античность │ Средневек. │…  │
│                    ^Кесарат ^вы ^Торн   ← флажки встреченных держав                │
├────────────┬──────────────────────────────────────────────────────┬────────────────┤
│ ХОЗЯЙСТВО  │                                                      │ ИРРИГАЦИЯ      │
│ Земледелие │ [Мотыга]──[Ирригация]─┬─[Севооборот]                 │ +15% фермам у  │
│ Добыча     │ [Кремень]──[Медь]      └ или ─[Террасы]              │ рек            │
│ Торговля   │                                                      │ ☾ эврика 1/2   │
│ ОБЩЕСТВО   │  ╔═ ВЕЛИКАЯ РАЗВИЛКА ═══════════════════════╗        │ −20%: знают    │
│ Право      │  ║ Храмовое царство │ Речная держава │ Степной║        │ 2 соседа       │
│ Вера       │  ╚══════════════════════════════════════════╝        │ [Исследовать] │
│ ВОЕННОЕ ░░ │  (серые дорожки до фазы 2)                           │ Shift — в очередь│
└────────────┴──────────────────────────────────────────────────────┴────────────────┘
```

- **Раскладка:** колонки — 11 эпох, строки — 9 гражданских дорожек в группах Хозяйство / Общество / Знание (+5 военных серых). Координаты заданы в данных (`Lane`, `Order`), авто-раскладки нет. `x = начало эпохи + Order·184`, `y = дорожка·72`.
- **Карточка 168×56:** иконка 16 px, название Fira 500 12,5, срок в tnum.

  | Состояние | Вид |
  |---|---|
  | изучено | графит, белый текст |
  | доступно | белая |
  | закрыто | `P3`, серый текст |
  | в работе | полоска прогресса по низу |
  | отвергнутая развилка | штриховка 45° с подписью «закрыто навсегда» |

  Значки: полумесяц эврики с прогрессом; «−20%» — распространение знаний (тултип раскладывает все множители и показывает, кто из встреченных уже знает технологию); замок — не хватает требований.
- **Слоты:** 2 на старте, до 6 позже. Очередь до 3 на слот. Реальный срок `ETA = остаток / очки_за_такт × такты_в_секунду(speed)`.
- **Линейка эпох:** «Древний мир: 7 из 15 до смены» и флажки встреченных держав — гонка видна прямо здесь. Развилки невстреченных держав скрыты (вопрос 39).
- **Великая развилка:** три карточки 240×120 со скобкой «или», значки выбравших встреченных держав. Путь, совпадающий со склонностью, стоит на 25% дешевле, об этом говорит плашка.
- **Режимы:** «Эпоха» (карточки) и «Обзор» (Z, точки 10 px, вся история на экране). Подписи дорожек и заголовки эпох закреплены при прокрутке. В кадре 40–60 карточек.
- **Действия:**
  - клик — в свободный или выбранный слот, Shift+клик — в очередь, можно перетащить на слот, правый клик — убрать;
  - наведение подсвечивает цепочку требований и включает превью на карте (§1.1).
- **Клавиши:** T; 1–6 — слот; стрелки — курсор; Enter — исследовать; Shift+Enter — в очередь; F — поиск; Z — обзор; Home — текущая эпоха.
- **Команда:** `SetResearch(nation, slot, techId)` / `QueueResearch`. Рёбра ортогональные со скруглением 8 px, рисуются одним `_Draw` только для видимой области; эпохи кешируются в SubViewport.

## 5. Политика · лист M · P · M1-лайт / M2 (E-9, E-10, S-13)

```
┌ Политика ─ [Законы] [Сословия] [Недовольство] [Правитель] ─────────── ×┐
│ ВОЖДЕСТВО  = Вождь + Старшинство + Совет старейшин                     │
├─────────────────────────┬──────────────────────────────────────────────┤
│ ГЛАВА ГОСУДАРСТВА       │            ▪▪▪▪▪▪▪▪▪▪                        │
│ (•)Вождь ( )Царь ( )Жрец│        ▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪   (M2: Совет 100)   │
│ НАСЛЕДОВАНИЕ            │      ▪▪▪▪  100 мест  ▪▪▪▪                   │
│ (•)Старшинство ( )Выбор │   Знать 41 · Жрецы 30 · Общинники 29        │
│ ТРУД  (•)Общинное ( )Раб│   за 58 · против 31 · всё равно 11          │
│ НАЛОГИ  Подать ▮▮▯▯▯     │ [портрет] Вождь Ардан II, 47 · Мудрый       │
│                         │   наследник: Ола, 19                        │
│ станете: ЦАРСТВО        │                                              │
│ [Провести указ · 40 влияния]              [Enter]                       │
└─────────────────────────┴──────────────────────────────────────────────┘
```

- **Шапка:** название формы правления (Alegreya 23) и формула-вывод, `GovName.Resolve(laws)`.
- **Сетка законов:** 8 категорий (Глава, Выбор главы, Опора власти, Вера, Труд, Экономика, Подданство, Налоги).
  - текущий закон — графитовая точка;
  - закрытые технологией — с замком и ссылкой на технологию;
  - законы одного ряда одной длины, эффект одной строкой, подробности в гиперподсказке.
- **Наведение на альтернативу:**
  - шапка показывает «станете: Теократия»;
  - карта — изменение настроения по провинциям (превью);
  - полукруг (M2) перекрашивается в «за / против / всё равно» (зелёный / красный / серый + ▲▼).
- **Принятие по форме правления:** указ (сразу, но стоит Влияния и даёт «Самодурство» −6 противникам); совещание (N УМ с шансом); голосование (M2: дата и прогноз).
- **Вкладка «Недовольство»:** термометр из 3 ступеней (ворчание → забастовки → отделение) с порогами. На каждой ступени — список провинций и требование радикалов с кнопкой «Выполнить».
- **Полукруг (M2):**
  - 100 мест делятся методом наибольшего остатка по политическому весу: численность × сила класса (знать ×5, жрецы ×3, общинники ×1, рабы ×0 — черновик);
  - места — квадраты 8×8 на 5 дугах;
  - обещания (M2): «построить храм за 5 УГ», не больше 2 за дебаты.

- **Замки:** оба игрока видят одно окно. Любая правка снимает оба замка. «Согласиться» работает, только когда закрепили оба.
- **Исполнение атомарное** в следующем такте. Если чего-то не хватает, сделка отменяется целиком.
- **Команды:** `ProposeDeal / EditDeal / LockDeal / AcceptDeal / CancelDeal`. Срок жизни — 120 реальных секунд, фиксируется при создании.
- **Название договора** собирается из пограничной провинции и товара, его можно переименовать. Сделка публична для всех, кто встретил обоих (вопрос 20), есть галочка «тайно».

- **Клавиши:** Enter — чат; F2 — готов; Ctrl+C — код; Esc — выйти.

## 18. Сетевая полоса и пауза · часть верхней панели · M2 (S-3)

```
│ [||] Осень 1142 ▮▮▮ │ [К]● [П]● [В]○ │ ПАУЗА: Вася · жетонов 2/3 · 0:32 │ ⌛2:14 │
```

## 20. Горячие клавиши (U-4)

Клавиши заданы через `physical_keycode`. Подпись в интерфейсе берётся из текущей раскладки (`DisplayServer.KeyboardGetLabelFromPhysical`), поэтому на ЙЦУКЕН «T» показывается как «Е». Альтернатива — русская мнемоника (вопрос 40).

| Группа | Клавиша (физ.) | На ЙЦУКЕН | Действие |
|---|---|---|---|
| Время | Пробел | Пробел | пауза |
|  | 1–5 / + − | — | скорость / шаг скорости |
| Экраны | T · P · M · D · R · N · L | Е · З · Ь · В · К · Т · Д | Технологии · Политика · Рынок · Дипломатия · Религия · Народ · Летопись |
|  | Esc | — | закрыть лист / меню |
|  | Ctrl+Tab | — | последние два листа |
| Режимы карты | F2–F7 | — | Рельеф · Политическая · Религия · Торговля · Плодородие · Недовольство |
|  | Shift+F2…F7 | — | Классы · Уровень жизни · Доступ · Эпохи · Цена · Ночь (позже) |
| Камера | Home / Backspace | — | к столице / назад (10 позиций) |
| Навигация | `.` / Shift+`.` | Ю | следующая / предыдущая тревога |
|  | Ctrl+K или / | — | «Найти что угодно» |
|  | H | Р | скрыть «Путь вождя» |
| Справка | F1 | — | Кодекс |
| Служебное | F8 | — | «Сообщить о проблеме» |
|  | F10 | — | настройки |
|  | F12 / Shift+F12 | — | скриншот / без интерфейса (постер) |
|  | Ctrl+S | — | быстрое сохранение (одиночная) |
| Разработка | ~ · Ctrl+F3 · Ctrl+F6 | Ё | консоль · оверлей производительности · перезагрузка дефов |
| Сеть | Alt+клик · Alt+перетаскивание | — | метка · мел |
|  | Ctrl+↑/↓ · F2 (лобби) | — | попросить скорость · готов |

Когда фокус в поле ввода, горячие клавиши выключены. Мёртвые клавиши Windows (issue Godot #118143) по умолчанию не используются, кроме `.` и `/`.

**«Найти что угодно» (Ctrl+K).** Нечёткий поиск по 5900 провинциям, державам, технологиям, законам, товарам, понятиям и настройкам. Нормализация: нижний регистр, ё → е. Порядок: префикс > начало слова > подпоследовательность + бонус за недавние. 8 строк, Enter — прыжок или открытие экрана. Индекс строится на `WorldReady`, <1 МБ, поиск на каждое нажатие <1 мс.

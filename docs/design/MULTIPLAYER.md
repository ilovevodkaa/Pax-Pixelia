# Pax Pixelia — мультиплеер: lockstep и социальные механики (v1)

Как 2–16 друзей делят одно время. Первая часть — техника: часы, команды, детерминизм, транспорт, лечение рассинхрона, вход и перехост. Вторая часть — то, ради чего всё затевалось: паузы, сделки, клятвы, гонки, итоги вечера. Коды идей (F-, S-, W-) ведут в [IDEAS.md](../IDEAS.md), вопросы — в [OPEN_QUESTIONS.md](../OPEN_QUESTIONS.md).

---

## 0. Принципы

1. **Одиночная игра = сетевая на одного.** Один конвейер команд с локальным транспортом и задержкой 0. Каждая ошибка синхронизации ловится ещё до того, как друзья сели в голосовой.
2. **Клиенты обмениваются только командами** (GDD §7). Состояние у всех одинаковое, потому что симуляция детерминирована.
3. **Время двигает только сетевой ход.** Кадровый delta в симуляцию не попадает.
4. **Никто не ждёт одного.** Нет модальных окон, у выбора есть таймер, паузы ограничены правилами, которые видны на экране.
5. **Звезда, а не P2P.** Все общаются с хостом, хост решает, что входит в ход. Обход NAT нужен только хосту.

## 1. Часы

Единицы времени ([IDEAS §0](../IDEAS.md)): такт → цикл (10 тактов) → условный месяц (10 циклов) → условный год (120 циклов).

| Параметр | Значение |
|---|---|
| Сетевой ход | 100 мс реального времени, 10 в секунду |
| Тактов на ход | x1 = 0,5 · x2 = 1 · x3 = 2 · x4 = 4 · x5 = 10 (дробная часть копится в целом счётчике) |
| На паузе | ходы идут, но с 0 тактов, поэтому команды исполняются: постройка, заказанная на паузе, появляется у всех через ~0,2 с |
| Порядок внутри хода | 1) команды хода по `(nation, seq)` → 2) такты движения → 3) цикл раз в 10 тактов, провинция `p` на такте `p % 10` |
| Бюджет симуляции | ≤30 мс на ход на x5 (p95), 0 аллокаций в установившемся режиме |

**Реализация**
- `Sim/TurnRunner.RunTurn(TurnPacket p)` — чистый C#.
- `Net/TurnPump.cs` на стороне Godot копит реальное время. Когда набралось 100 мс и пакет хода пришёл, он вызывает `RunTurn`. Отставший клиент прогоняет до 3 ходов за кадр.
- Сейчас в игре двое часов: `Game._Process` копит delta до `YearTick`, а `SimDriver` отдельно двигает разведчиков по своему аккумулятору с обрезкой `MaxFrame = 0,1 с`. На двух ПК с разным FPS разведчики разойдутся за минуту. Это чинит волна 1.5 (F-1).

## 2. Команды и журнал

```csharp
readonly record struct Cmd(int Tick, byte Nation, ushort Seq, CmdType Type, int A, int B, int C);
// ~20 байт в бинарном виде (varint); редкие большие команды — хвост до 256 байт
```

**Типы.**
- Сейчас: `Claim, Build, Survey, ScoutTo, ScoutAuto, SetResearch, QueueResearch, EnactLaw, SetTax, FoundReligion, ChooseOption, SetSpeed, SetDesiredSpeed, Pause, Unpause, Ready, SetController, RenameFeature, Cheat*`.
- M2: `ProposeDeal, EditDeal, LockDeal, AcceptDeal, CancelDeal, SwearOath, BreakOath, PlaceBet, ChooseEraFace`.
- Фаза 2: `MoveArmy, SetFrontOrder, DeclareWar, OfferPeace…`

**Правила**
- **Проверка повторяется при исполнении.** `Commands.Apply(w, s, in cmd, sink)` — это switch, который зовёт уже существующие `Rules.CheckX` и `Rules.X` с параметром `nation`. Состояние могло измениться, пока команда шла по сети.
- **Мгновенная подсказка в UI:** `Game.Claim(p)` сначала вызывает `ClaimProblem(p)` для тоста, затем `Game.I.Submit(Cmd.Claim(me, p))`. Тосты с ошибками локальные и в журнал не идут.
- **Боты, советник, регент, наместники и консоль** выдают те же команды. `Bots.Expand` возвращает `ClaimCmd`, а не зовёт `Rules.Claim`.
- **Состояние по державам:** `Gold[n]`, `Fog[n][p]` (16 × 5900 = 94 КБ), `Met[n*N+m]`, `Scout.Nation`, очередь стройки, `Controller[n] = Human(slot) | Bot(persona) | Regent(slot, orders)`. `LocalPlayer` остаётся только в UI как `Game.I.Viewer`.
- **Летопись по державам:** `ISimSink.Notify(nation, key, args)`, UI фильтрует записи по зрителю. Колода событий получает свою соль на каждую человеческую державу, чтобы у всех выпадали разные события.
- **Вне симуляции** (каналы 1–2, в журнал сессии, но не в `GameState`): чат, метки, мел, эмоции, курсоры, переписка.

## 3. Детерминизм

- **Почему целые.** На x64 с SSE2 в одной версии .NET операции + − × ÷ и `Sqrt` побитово одинаковы. Но `Math.Sin/Cos/Pow/Exp/Log/Atan2` уходят в CRT (ucrtbase, glibc, libm) и могут отличаться на 1 ulp между ОС и версиями. Поэтому в Sim только целые, деньги в `long` (сотые), люди в `int`, доли в ‰, нелинейности — таблицами. Тригонометрия, если понадобится, — таблица с интерполяцией в `Core/DMath.cs`.
- **Линтер** (`tools/lint-sim.ps1`, позже Roslyn `PAX001…`). В `Sim/` и `World/` запрещены:
  - `System.Random`, `DateTime`, `Environment.TickCount`, `Guid`;
  - `string.GetHashCode()` (в .NET рандомизирован для каждого процесса);
  - перебор `Dictionary/HashSet` без сортировки;
  - `Parallel.*`, `async`;
  - `Math.Sin/Cos/Tan/Atan2/Exp/Log/Pow`, `MathF.*`;
  - пространство имён Godot.

  Исключение — комментарий `// pax-allow`.
- **Генератор мира** вызывает `Math.Sin/Cos/Atan2/Log2` (`WorldBuilder.Provinces.cs`, `Terrain.cs`, `GenScale.cs`) и портирован из JS побитово. Его не трогаем, а в лобби сверяем **`WorldHash`** — xxHash64 от `Prov`, `PLand`, `PFert`, `Adj`. При несовпадении хост стримит пакет мира (≈2–3 МБ Brotli). Центроиды провинций для правил считаются без `Atan2`.
- **Тест-двойник** (`tests/SimTests`):
  - два состояния из одного сида;
  - фаззер подаёт случайные валидные команды за 16 держав на 20 000 ходов, хеши по разделам сравниваются каждый ход;
  - посередине один двойник делает save → load — так ловится состояние, которое забыли сохранить;
  - второй двойник работает в другом потоке и с `CultureInfo("en-US")`.
- **`--selftest=5000`** прогоняет 5000 ходов скриптованных команд и печатает хеш. Друзья сравнивают его в чате — проверка ПК против ПК за минуту.
- **Бинарник у всех один** (x64 Windows). Если появятся Mac ARM или Linux, линтер и `WorldHash` становятся критичными (вопрос 12).

## 4. Транспорт

```csharp
interface ITransport {
  void Host(int port); void Join(string addr);
  void Send(int peer, int channel, ReadOnlySpan<byte> data);
  event Action<int, int, byte[]> Packet; event Action<int> PeerLost;
}
```

| Реализация | Когда | Заметки |
|---|---|---|
| **Loopback** | всегда | одиночная игра и тесты |
| **LiteNetLib** (MIT, чистый C#) | M2, рекомендую основной | тестируется в `tests/NetTests` без Godot, есть `SimulateLatency`/`SimulatePacketLoss` и NAT punch |
| ENet (`ENetConnection` из Godot) | M2, запасной | готов в движке, но для тестов нужен Godot |
| **Steam Networking Sockets** | M4 | Facepunch.Steamworks, релей SDR без проброса портов, IP скрыт, лобби и приглашения через оверлей; для тестов AppID 480. У GodotSteam нет C#-версии |

- **Каналы:** 0 — надёжный упорядоченный (ходы и команды); 1 — надёжный (чат, сделки, снимки); 2 — ненадёжный (метки, курсоры).
- **Трафик:** пакет хода ≈8 байт + ~20 байт на команду, 10 Гц. Меньше 1–2 КБ/с на клиента даже при 16 игроках.
- **Подключение до Steam** (вопрос 12). Лобби показывает 4 способа:
  - а) **UPnP** — класс `Upnp` в Godot, пробуем автоматически первым;
  - б) **Radmin VPN / ZeroTier / Tailscale** — виртуальная LAN, популярна у русскоязычных игроков, кода не нужно;
  - в) проброс UDP-порта вручную, с понятной ошибкой «друг не может подключиться — откройте порт N»;
  - г) свой ретранслятор (noray или NAT punch LiteNetLib) на VPS за 300–500 ₽ в месяц с кодом комнаты вида **ЛИСА-42**.

  У мобильных операторов CGNAT, там помогут только б) и г).
- **Discord** в РФ заблокирован, поэтому Rich Presence отброшен.

## 5. Задержка ввода, «призраки», слабый ПК

- **Задержка D.** Команда исполняется через D ходов. Хост каждые 5 с считает `D = clamp(ceil((maxRTT/2 + 2·джиттер + 20 мс)/100 мс), 1, 6)` и рассылает всем. Для друзей по России: Москва–Питер (RTT 10–20 мс) → D = 1; Москва–Новосибирск (50–70 мс) → D = 2; ретранслятор добавляет 20–40 мс. Хост может закрепить D вручную.
- **«Призраки».** Клик сразу даёт отклик: UI держит `PendingCmds` по паре Nation+Seq.
  - постройка — леса с песочными часами;
  - присоединение — штриховка своим цветом;
  - казна — «1240 (−50)».

  Когда команда исполнилась, короткая анимация подтверждения. Если её отклонили при исполнении, призрак «лопается» и показывает причину.
- **Буфер** 1–2 хода. Отставший больше чем на 3 хода прогоняет до 3 ходов за кадр (как в Factorio).
- **Нет пакета** — ждём, в углу нейтральная надпись «ждём Петю…». Хост знает, кто последним подтвердил ход.
- **Слабый ПК.** Клиенты сообщают p95 времени хода. Если у кого-то оно больше 60 мс на скорости N, хост снижает потолок скорости: «x5 недоступна: слабый ПК у одного из игроков», имя — в тултипе. Без стыда и без номинаций.

## 6. Сверка хешей и автолечение

- **Когда и как.** Каждые 10 ходов (1 с) клиент считает xxHash64 (`System.IO.Hashing`) по `MemoryMarshal.AsBytes` массивов состояния.
- **Разделы:** владельцы, население, настроение, постройки, казна и рынок, туман, разведчики и караваны, летопись и колода, законы, религии, контракты и клятвы, сессия. Итого 12 × 8 = 96 байт.
- **Стоимость:** 1–2 МБ состояния ≈ 0,2 мс.
- **Хост сравнивает хеши за ход T. Если не совпали:**
  1. баннер «Рассинхрон у Пети — чиним…», остальные играют дальше;
  2. хост сериализует `GameState` на ход T (`BinaryWriter` + Brotli, 0,3–1 МБ) и шлёт кусками по 64 КБ;
  3. клиент загружает снимок и догоняет буфер ходов;
  4. хост и клиент пишут в `user://desync/<время>/` дамп расходящегося раздела и журнал последних 600 ходов — это прикладывается к багрепорту (F8).
- **3 рассинхрона за 10 минут** — игра предлагает перехост. Секционный хеш сразу говорит, какая система сломалась («Рынок», «Туман»).

## 7. Вход в идущую партию, переподключение, регент

### 7.1 Вход (S-4, M2a)

1. Клиент шлёт `Hello` (версия, контрольная сумма контента, сид), генерирует мир (~0,7 с) и шлёт `WorldHash`.
2. Хост снимает изменяемую часть `GameState` на ход T плюс изменения карты: 50–200 КБ в MVP, 0,3–1 МБ с попами. Шлёт кусками по 64 КБ, не быстрее 1 МБ/с, и параллельно пересылает все пакеты ходов с T.
3. Клиент загружает снимок и прогоняет буфер без рендера, не меньше чем в 20 раз быстрее реального времени. Когда в буфере меньше 2 ходов — клиент в игре.
4. Остальные видят тост «Петя подключается… 63%». Слабый ПК, не успевающий догнать, получает автопаузу «ждём Петю» до 30 с.
5. Выбор державы: список свободных (флаг, население, эпоха) → `SetController`. Переподключение работает так же, своя держава возвращается по токену (ник + случайный ключ в сейве; в Steam — SteamID).

### 7.2 Регент (S-4)

По GDD вылетевшего заменяет бот. Наш регент — осторожный бот с **наказом**, оставленным заранее:
- варианты наказа: копить / строить еду / расширяться / наука / порты;
- дополнительно: «принимать сделки от Пети до 100 золота».

**Ограничения:** регент не меняет законы и веру, не рвёт клятвы, не предлагает сделок людям, тратит не больше 50% казны. Код — тот же `Sim/Bots` через советника с урезанным набором команд. Возможен штраф −10% к росту при регенте (решение по вопросу 46).

При первом вылете 30 с автопаузы, потом правит регент. Летопись: «Правитель Варгии отбыл на охоту. Страной правит регент». При возвращении — отчёт: «Построено 3 фермы, казна +220, население +4%».

## 8. Сейв у каждого и перехост

- Состояния у всех одинаковые, поэтому **каждый клиент молча пишет свой автосейв**: каждые 5 реальных минут и на каждой смене эпохи, последние 6 по кругу, в `user://saves/<сессия>/auto_<ход>.pax`. Внутри: сид, `GameState`, номер хода, таблица игрок → держава, статистика вечера, хеш.
- **Хост упал** → у всех окно «Хост пропал. Перехостить с хода 18 400?». Первый нажавший становится хостом, остальные переподключаются по коду комнаты. Все сверяют хеш своего сейва того же хода, и это доказывает, что никто ничего не потерял. Теряется не больше 5 минут игры.
- **Позже — настоящая миграция.** Список преемников по порядку входа. Если хост молчит 5 с, все подключаются к преемнику. Тот собирает у каждого номер последнего полученного хода, дорассылает недостающее и продолжает без отката. Естественнее всего это ложится на Steam-релей.

## 9. Лобби (S-2, M2a)

- **Код комнаты:** Crockford base32 от IP:порта (позже ID ретранслятора или Steam), 8 символов без похожих букв, или человеческий «ЛИСА-42» у ретранслятора.
- **Проверки:** версия сборки, контрольная сумма контента (4 символа, как checksum у Paradox; моды графики её не меняют), `WorldHash`. Отказ объясняется понятно: «У хоста 0.2.37, у тебя 0.2.35, обнови через itch».
- **Настройки хоста:**
  - сид и размер (пресеты малая ≈1500 / средняя ≈3000 / большая 5900 — вопрос 23);
  - боты 0–15, туман, темп (Быстрая / Обычная / Эпическая);
  - «Резинка», кризисы Лика, число вер, обмен технологиями (вопрос 19);
  - пресет пауз, «Дружеские подколки», «Летописец».
- **Дистанция старта:**
  - «соседи» — BFS 8 провинций, ~10 мин до встречи;
  - «близко» — 15 провинций, ~30 мин;
  - «далеко» — 25 провинций, ~60–90 мин;
  - «разные континенты».

  Кочевье всё равно сдвинет точку.
- **Страж цветов:** цвет ближе 0,10 в OKLab к человеку (0,06 к боту) даёт чип «слишком похож на Кесарат» и 3 ближайших свободных цвета.
- **Мастерская флагов:** пока генерируется мир, все одновременно собирают флаги. Черновик (`FlagSpec`, ≈8 байт) рассылается раз в секунду, миниатюры обновляются у всех. Профиль народа хранится в `user://nations/` и переходит из кампании в кампанию.
- **Сейв:** слоты показывают сохранённые державы, свободные — «свободно — занять». Отвалившегося заменяет регент или бот.
- Экран: [SCREENS §17](SCREENS.md).

## 10. Скорость и паузы (S-3)

**Скорость задаёт хост** (GDD §7). Желания игроков видны флажками под делениями скорости. Любой может нажать «Помедленнее» (Ctrl+↓), у хоста всплывает счётчик голосов.
- **Опция лобби «Минимум желаний»:** игра идёт на минимуме желаний людей онлайн, но не выше потолка хоста. Кто 3 минуты ничего не трогал, не учитывается. Галочка «Замедлять, пока я в меню» держит желание игрока не выше 2, пока открыты законы, технологии или сделка.

**Пресеты пауз** (вопрос 3):

| Пресет | Правила | По умолчанию |
|---|---|---|
| **Свои люди** | без лимита, снять может любой | 2–4 человека |
| **Честно** | жетоны и «Совет» (ниже) | 5+ человек |
| **Турнир** | пауза только у хоста | — |

**«Честно»**
- **Жетоны.** У каждого 3; +1 за 10 реальных минут, максимум 3. У хоста лимита нет.
- **Короткая пауза** (Пробел или P) стоит 1 жетон и длится до 45 с, потом баннер «Продолжаем через 5…» и автоснятие. Снять раньше может только тот, кто поставил, или хост — конец «войне пробелов».
- **Продлить** может другой игрок своим жетоном, +45 с: «Петя продлил паузу».
- **«Совет»** (удерживать P 1 с): полная пауза, пока все люди не нажмут «Готов», как проверка готовности в Dota. Причина одной кнопкой: Событие / Думаю / Чай / Отойду. Через 3 минуты большинство может продолжить. Один Совет на игрока за 15 минут.
- **«Чайный перерыв»:** предлагает любой, большинство голосует. 10 минут, жетоны не тратятся.

**Автопаузы:** человек отключился — 30 с на возвращение; первая встреча двух людей — 5 с. Лечение рассинхрона идёт фоном, без паузы.

**События не ставят игру на паузу:**
- таймер 60 реальных секунд фиксируется в момент выпадения (на x5 он не превращается в 18 с);
- «Советник выберет: …» видно заранее;
- сделки живут 120 с;
- в одиночной игре автопауза на событиях включена по умолчанию.

Пауза, продление, «Готов» и желаемая скорость — команды журнала, поэтому детерминированы и попадают в «Итоги вечера».

## 11. Социальные механики

### 11.1 Сделка «два замка» и контракты (S-5)

- **Что можно положить:** золото сразу; золото или товар за УГ на N УГ; технологию (получатель получает 50% прогресса, вопрос 19); карты (обмен изведанным); право прохода; клятву; пари.
- **Замки:** оба видят одно окно. Любая правка снимает **оба** замка — защита от подмены в последнюю секунду. «Согласиться» работает, когда закрепили оба. Исполнение атомарное: не хватило — отмена целиком.
- **Контракт** `Contract{id, a, b, пункты, начало, конец, залог}` исполняется в торговом шаге раньше автономной торговли. Недопоставка — пропорциональная оплата и запись «просрочка» в летопись.
- **Название договора** собирается из пограничной провинции и товара («Медный договор у Серых холмов»), его можно переименовать.
- **Видимость:** по умолчанию сделка публична для всех, кто встретил обоих, есть галочка «тайно» (вопрос 20). Для Steam у хоста будет «лимит подарков».

### 11.2 Пари

`Bet{a, b, условие, ставка, крайний срок}`. Ставки обеих сторон держит мир, условие проверяется раз в УМ. Около 12 типов:
- первым в эпоху X;
- больше населения, провинций или дохода к дате;
- первым основать веру;
- N портов или чудо;
- первым встретить N держав;
- изведать M% мира.

Лимит — 25% казны. Номинация «Азартный».

### 11.3 Клятвы с залогом (S-6)

| Клятва | Суть |
|---|---|
| Раздел земель | игроки рисуют линию с привязкой к границам провинций; N УГ нельзя присоединять за линией |
| Торговый союз | пошлины −50% |
| Обмен картами | постоянный общий обзор |
| Научный союз | +15% к диффузии между участниками |
| Таможенный союз (Later) | общий рынок |

- **Залог** (золото или товары) держит мир. Порвать клятву можно кнопкой в любой момент.
- **При разрыве:** залог уходит пострадавшему; нарушитель получает **«Клеймо клятвопреступника»** на 25 УГ — −10% к торговому доходу со всеми и значок у флага. Запись видят все, кто его встретил: «Варгия нарушила Клятву Серых холмов».
- **Гарант** — третий игрок-свидетель, получает 25% залога.
- **В фазе 2** разрыв даёт пострадавшему и гаранту повод к войне.
- Нарушать или нет в мирном MVP — вопрос 11.

### 11.4 Дуэты (S-7)

События-дилеммы на двоих: «Спорная река», «Белый слон», «Заблудший караван» и др. ([CONTENT §16](CONTENT.md)). Эффекты ±5–10% и временные. В лобби переключатель «Дружеские подколки».

### 11.5 Фотофиниш (S-8)

- **Как решается спор.** Хост присваивает `Seq` по времени прихода и пишет в заголовок команды миллисекунды внутри хода (ushort) — это часть пакета, поэтому детерминировано. Вторая команда на ту же цель (провинцию, веру, чудо, догмат) проваливается при исполнении, затраты возвращаются.
- **Как объявляется.** Тост «Фотофиниш! Вася успел на 0,3 с раньше». При разнице меньше 1 с — запись в общую летопись. Для гонок (вера, чудо, первая эпоха) — фанфара и номинация.
- **Честность хоста:** его собственные команды встают в очередь с искусственной задержкой, равной среднему полупингу клиентов.

### 11.6 Метки, мел, чат, звуки (S-8)

- **Метки.** Alt+клик открывает колесо из 4 меток (Смотри / Моё / Предлагаю / Осторожно): пиксельный маркер на 4 с + звук, не больше 3 меток за 5 с. Alt+Shift+клик — метка только одному. Туман соблюдается: метка в неизведанном видна как точка в облаках.
- **Мел.** Alt+перетаскивание рисует линию цвета державы, живёт 10 с (всем или только партнёру по сделке).
- **Чат:** общий, шёпот, чат участников клятвы. Кнопка «заглушить игрока».
- **Звуки для голосового чата:** рог первой встречи, аккорд предательства, фанфара эпохи, щелчок фотофиниша. Горячие клавиши не занимают V, CapsLock, `` ` ``, Mouse4 и Mouse5 (push-to-talk).
- **Эмоции правителя** (Later): 8 штук пузырём над столицей на 5 с.

### 11.7 Общая летопись и «Встреча миров»

- **Видимость записи:** личная / пара / мир (видят все, кто встретил участника). Не больше 1 мировой записи одного типа за 10 УГ.
- **Первая встреча двух людей:** автопауза 5 с, оба флага выезжают навстречу, звучит рог: «Встреча двух миров: разведчики Варгии увидели костры Эльмарии».
- **Анонсы гонок** с учётом тумана: «Эльмария первой вступила в Античность; Варгия отстаёт на 2 технологии», «Некий далёкий народ первым обошёл мир».
- **Эмиграция как мирное соперничество** (S-12): «2 000 ремесленников Варгии переехали в Эльмарию: там платят больше».
- **Фильтры:** Моё / Соседи / Мир. Клик по записи переносит камеру.

### 11.8 Итоги вечера и «Ранее в Pax Pixelia» (S-11)

- **«Остановиться на рубеже»:** хост выбирает веху — конец года, смерть правителя, новая эпоха у кого угодно или «через 10 минут». На вехе — пауза, автосейв и итоги.
- **Слайды (30–60 с):**
  1. реальное время и игровые годы;
  2. таймлапс границ за вечер (15 с);
  3. карточки игроков (прирост, доход, спарклайны, прозвище правителя);
  4. номинации;
  5. цитата вечера.

  Экспорт PNG 1200×675 и GIF. `SessionStats` считается из журнала команд, у всех одинаковый.
- **Номинации только беззлобные:** Торгаш, Застройщик, Скаут-маньяк, Фотофиниш, Сова (играл после 01:00), Щедрая душа, Азартный, Пауза-мейкер, «Сделай отдых» (вечер дольше 4 ч).
- **«Ранее в Pax Pixelia…»** — 20 с в начале следующего вечера: 5 главных мировых записей прошлого раза и номинации.

### 11.9 Таймлапс и реплеи

- **Таймлапс.** Раз в УГ пишется `OwnerDelta` (провинция ushort, владелец sbyte, ≈20 изменений × 3 байта) плюс маркеры (город, эпоха, вера, чудо), около 2 МБ на 500 УГ. Проигрыватель перекрашивает текстуру владельцев существующим шейдером. GIF собирается своим LZW-кодером. От версии игры не зависит.
- **Реплей = сид + начальное состояние + журнал.** 8 игроков × 6 команд в минуту × 8 ч ≈ 23 000 команд ≈ 460 КБ. Перемотка — через автосейвы как ключевые кадры, переключатель тумана «глазами Пети». Валиден только для той же `SimVersion`. Это ещё и лучший инструмент отладки рассинхрона: `ReplayRunner x.pxr --verify` → «Расхождение на такте 5312: Owner[2211] 3 ≠ −1».

## 14. Тесты и бюджеты

**Сетевой полигон** (`tests/NetTests`, чистый C#, ≈1 мин в CI):
- хост и 3–7 клиентов в одном процессе через loopback;
- задержка 30–300 мс, потери 5–10%;
- случайные паузы и снятия, смена скорости, клиент отваливается и возвращается, один клиент медленный;
- 10 000 тактов.

Проверяем: хеши совпадают, простой ходов ограничен.

| Величина | Бюджет |
|---|---|
| Сетевой ход | 100 мс |
| Симуляция на ход, x5, 16 держав | ≤30 мс p95 |
| Хеш по разделам | ≈0,2 мс раз в 1 с |
| Трафик на клиента | ≤2 КБ/с |
| Снимок для входа | 50–200 КБ (MVP), 0,3–1 МБ (с попами) |
| Сейв | 0,4–0,6 МБ, фриз ≤30–50 мс |
| Реплей на 8 ч | ≈460 КБ |
| Таймлапс на 500 УГ | ≈2 МБ |
| Перехост | < 1 мин, потеря ≤ 5 мин игры |

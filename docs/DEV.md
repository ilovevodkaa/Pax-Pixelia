# Pax Pixelia — как запустить и разрабатывать

## Что нужно
- **Godot 4.7.1 .NET**: лежит в `tools/godot/Godot_v4.7.1-stable_mono_win64/`. Обычная сборка без .NET не подойдёт, игра на C#.
- **.NET SDK 8** (уже установлен).

## Открыть в редакторе
1. Запусти `tools/godot/Godot_v4.7.1-stable_mono_win64/Godot_v4.7.1-stable_mono_win64.exe`.
2. Выбери «Импорт» → `D:\supergae\game\project.godot`.
3. Нажми F5, чтобы запустить игру. Главная сцена — `scenes/Front.tscn` (титул «PAX PIXELIA» → «Новая игра» → карта); `scenes/Main.tscn` — сама партия.

## Запуск из консоли
```bash
cd game && dotnet build
../tools/godot/Godot_v4.7.1-stable_mono_win64/Godot_v4.7.1-stable_mono_win64_console.exe --path . -- --seed=42
```
Флаги Godot (например `--resolution 1280x720`) ставятся **до** `--`, флаги игры — **после**.

Без флагов открывается главное меню. Если есть любой игровой флаг (`--seed`, `--shot`, `--selftest`…) и нет флагов `--front*`, меню сразу уступает место `Main.tscn`, так что все проверки и скриншоты работают как раньше. Первый раз после клонирования выполни `... --headless --path game --import`, чтобы Godot импортировал шрифт, звуки и картинки.

## Проверки
| Команда | Что делает |
|---|---|
| `... --path game -- --selftest [--selftest-shots=папка]` | прогоняет игру по сценарию (запуск, календарь и эпоха, режимы карты, масштабы и шов, подсказка, панели, присоединение, стройка, геологи, разведчики и туман, пауза и скорость в тактах, смена месяцев, наблюдатель, лидеры, окно события и ответ командой, Esc → меню паузы, «Новый мир», окно 1280×720), печатает `PASS`/`FAIL`, код выхода = число провалов. Без `--noinput`: щит глотает и искусственные клавиши |
| `... --path game -- --front-selftest[=full\|loop\|continue]` | главное меню с клавиатуры: обход экранов, стек, Esc, PxConfirm, «Загрузить», мир для планеты. `full` — ещё «Новая игра» → `Main.tscn` на мире из меню; `loop` — трижды титул → «Новая игра» → «Народ» → НАЧАТЬ → карточка главы → карта → Esc → пауза → «В главное меню» (автосохранение) → титул, и проверка, что узлы, объекты и память не растут; `continue` (нужны сохранения, например после `loop`) — «Продолжить» → карточка главы → ровно сохранённая партия, затем пауза → «Загрузить» → другое сохранение, а брошенная партия уходит в автосохранение |
| `... --path game -- --savetest [--headless]` | сохранения в настоящей игре (своя папка `user://savetest`): сохранить посреди игры (разведчик на полпути, события) → играть дальше как эталон → загрузить → состояние, журнал, камера, режим карты, выбор и память карты те же, через 1200 тактов хеш = эталон; битые, чужие, новые, пустые, отсутствующие файлы и «другой мир» отклоняются, текущая партия не страдает; 3 слота автосохранений по кругу; сохранение при выходе не пишет поверх загружаемого; календарное автосохранение; крестик окна (Alt+F4); список, «последнее», удаление; бюджеты: сохранение < 300 мс работы, загрузка < 1,5 с вместе с миром |
| `... --path game -- --perf [--perf-seconds=4]` | вертикальная синхронизация выкл.; время генерации по этапам, кадры при ×1/×3/×8 (стоя и в движении), кадры с разведчиками на скорости 5, память; замер правил без карты: мкс на такт и на такт с циклом, худший такт, байт на такт |
| `... --path game -- --pacing [--pacing-hours=60] [--headless]` | партия одних ботов на текущем мире, три пресета параллельно: когда лидер входит в каждую эпоху (дата, реальные часы на x3, дней за такт), затем выход (~1 мин) |
| `... --path game -- --inputtest` | настоящие события мыши и клавиатуры: наведение, колесо, перетаскивание, щелчок, Esc, +/−, смена размера окна, прыжок камеры |
| `... --headless --audio-driver Dummy --path game -- --sfxprobe [--sfxlog]` | звук: каждое событие по разу на паузе (фишка, зум по тону, панорама без звука, режимы, туман, пауза/скорость и Пробел, золото, присоединение, отказ, стройка, геологи, разведчики, заметки, события колоды каждого класса, окно выбора, фанфара эпохи после вдоха тишины, наведение и нажатие в HUD, меню паузы без защёлки) — ровно ожидаемые звуки; затем 20 с на скорости 5 с разведчиками, панорамой и зумом: ни один звук не чаще своего интервала, не больше 4 в секунду. Код выхода = число провалов |
| `cd tests/WorldGenTests && dotnet run -c Release` | генератор мира: инварианты, качество рек (без гребёнок и прямых), золотые хеши сидов 1337/42/777, детерминизм по числу потоков, бюджет 600 мс. После намеренного изменения — посмотреть `--png=папка [--crops=x,y;…]` и перезапустить с `--bless` |
| `cd tests/ContentTests && dotnet run -c Release [seed=N] [pace=480\|1000\|1600] [verbose]` | проверка game/data (ключи, тон, шутки со справкой) и сухой прогон колоды событий на всю партию: событие раз в ~67 с, детерминизм |
| `cd tests/SimTests && dotnet run -c Release [-- pacing\|bench\|saves]` | правила без Godot: линтер детерминизма, часы и календарь, туман, разведчики по тактам, команды, экономика, 1400 циклов, детерминизм при любой нарезке тактов и частоте кадров, реплей журнала (и для двух людей), сохранения (файл целиком в неудобные моменты: сразу после присоединения, разведчик на полпути, пауза, открытый выбор события — загрузка и игра дальше = непрерывная партия бит в бит; ревизия полей состояния; хеш мира; порча, обрезка, старые и новые форматы → только `SaveException`; бюджеты), состав держав, колода событий (окно выбора и команда `Choose`), быстрый pacing. `pacing` — полный отчёт по трём пресетам (с колодой событий), `bench` — только замер правил, `saves` — только сохранения |

## Сохранения (F-4)
- **Файл `.pxs`** (`Core/Save/SaveFile.cs`, чистый C#): `PXSV` · формат u16 · заголовок с контрольной суммой (версия игры, вид, имя, время записи, время в игре, `GameSetup` с народом игрока, дата, эпоха, держава с цветом и флагом, такт, размеры и хеш мира, хеш состояния, подпись колоды событий) · тело, сжатое deflate, с контрольной суммой: чанки `STAT` (снимок `GameState`), `JRNL` (журнал команд и счётчики `Seq`), `VIEW` (центр камеры, масштаб, режим карты, выбранная провинция, память карты о давно не виденных землях). Неизвестные чанки пропускаются. Списки читают только заголовок; миниатюра 320×180 лежит рядом (`<имя>.png`).
- **Снимок** (`Sim/GameState.Save.cs`): поле за полем через `BinaryWriter`, без отражения: время и календарь, состав держав, `Nat[n]` (казна, наука, эпоха, проекты, туман, встречи, последний виденный владелец), провинции, постройки, пути, разведчики (с подшагом), память колоды событий по id (кулдауны, одноразовые, флаги, нити, открытый выбор, отложенные последствия). Случайность `SimRng`/`ContentRng` — хеш от зерна и такта, отдельного состояния у неё нет. Мир не сохраняется: он пересоздаётся из зерна и размера и сверяется `WorldHash`. Новое поле в `GameState`/`NationState`/`NationFog`/`Scout`/`EventMemory` — записать и прочитать в `GameState.Save.cs` и поднять `SnapshotVersion`: иначе упадёт ревизия полей в SimTests.
- **Загрузка** `Game.I.LoadGame(путь)`: файл читается и проверяется до того, как что-то меняется; затем текущая партия сбрасывается, мир пересоздаётся (`LoadStarted` → карточка главы показывает державу, эпоху и дату сохранения), хеш мира и состояние (хеш и заново записанный снимок) сверяются, журнал и вид восстанавливаются, дальше `WorldReady` как у новой игры. Загруженная партия стоит на паузе. Из меню и из паузы загрузка идёт через `Session.Pending.LoadPath` и `Main.tscn`; не загрузившееся сохранение возвращает на титул с причиной и больше не предлагается в «Продолжить».
- **Автосохранение** (`Core/Save/AutoSaver.cs`, ребёнок `Game`): раз в 10 игровых лет, но не чаще раза в 3 реальные минуты; при «В главное меню», «Выйти из игры» и перед загрузкой другого сохранения из паузы (никогда поверх выбранного); крестик окна / Alt+F4 — синхронно (`AutoAcceptQuit = false`, ≈10 мс, миниатюра на CPU). Три слота `auto_1..3` по кругу, ручные — `manual_<время>.pxs` (имя в заголовке, то же имя перезаписывается после вопроса). Запись через временный файл и переименование. Там же счётчик «времени в игре».
- **Интерфейс:** на титуле «Продолжить» (самое новое целое сохранение, вторая строка «держава · дата · время в игре · когда») и «Загрузить» (неактивна без сохранений); экран «Загрузить» (`UI/Front/LoadScreen.cs`: миниатюры, держава, дата, эпоха, время в игре, удаление через PxConfirm, битые файлы приглушены с причиной); в паузе «Сохранить» (имя, `PxConfirm.AskText`) и «Загрузить»; тихая плашка «Сохранено» в правом нижнем углу (`UI/SaveIndicator.cs`).
- Замеры (мир 2560×1440, 16 держав): сохранение ≈35 мс работы с отрисованной миниатюрой (+1 кадр ожидания), синхронное ≈7 мс, файл ≈35 КБ; загрузка ≈0,3–0,45 с вместе с пересозданием мира.

## Время, календарь и команды
**Один такт — одни часы.** Все правила считают такты постоянной реальной длины (`Sim/Clock.cs`). Скорости 1–5 = **2 / 4 / 8 / 16 / 40 тактов в секунду**. Реальное время превращается в такты целым счётчиком (`Sim/TickPump.cs`): после любого отрезка времени тактов ровно ⌊мкс × тактов в секунду / 10⁶⌋, как бы он ни был нарезан на кадры; кадр длиннее 0,25 с обрезается. Второго счётчика нет.
- Каждый такт: шаг разведчиков (16 из 40 подшагов на провинцию: 2,5 такта = 0,31 с на x3). Каждый 4-й такт — **цикл правил** (0,5 с на x3, как бывший «год»): налоги и содержание, материалы, рост населения, довольство, наука и эпохи, проекты столиц, боты, колода событий.
- **Наука** — запас очков прогресса у каждой державы (`Nat[n].Progress`): мудрецы 4 + земли до 4 (1 за 5 провинций) + святилища до 2 (1 за 2), +25% тем, кто отстал от эпохи лидера. Эпоха державы — по таблице порогов `Sim/Eras.cs` (11 эпох, стоимость каждой × `PacePermille` / 1000). Будущее дерево технологий будет кормить тот же запас.
- **Календарь выводится из прогресса лидера**, а не из прошедшего времени (`Sim/Calendar.cs`): таблица 11×17 в `Day256` (дни × 256 от 1 января 4000 до н. э.). Каждая эпоха начинается ровно 1 января своего года на любом пресете: Древний мир 3090 до н. э., Античность 880 до н. э., Средневековье 620, Возрождение 1410, Пар 1730, Индустриальная 1855, Атомная 1930, Информационная 1980, Космическая 2025, Будущее 2070. Дата плавно догоняет цель за цикл. На x3 это ≈ месяц за такт в Первобытную, несколько дней в Средневековье и доли дня в новое время. Года 0 нет.
- Текст даты (`Game.I.DateText`): «март 3200 до н. э.», пока такт длиннее 15 дней, потом «12 марта 1893» (до 1000 г. — «1 мая 620 н. э.»).
- Проверено `pacing`: Быстрая 12,0 ч · Обычная 25,0 ч · Эпическая 40,0 ч на x3 до Будущего, эпохи в свои годы.

**События** — данные в `game/data` (151 событие: летопись, выбор, пасхалки, нити, мировые), колода `Content/EventRunner` (чистый C#, целые числа). `Sim/SimEvents.cs` привязывает её к партии: у каждой державы своя память, колода сдаёт раз в 90–180 циклов (45–90 с на x3), выбор — раз в 360–480. Боты отвечают по весам ИИ, игроку открывается окно (`UI/EventWindow.cs`), ответ — команда `Choose`; без ответа к сроку берётся первый вариант. Эффекты — казна, довольство, население в ‰, наука; остальные показатели (стабильность, культура…) пока нейтральны, и события, которым нужны несуществующие системы, в колоду не попадают. Итог пишется в летопись. `GameSetup.JokePercent` — «Летописец» (0/100/200).

**Всё — приказ.** Любое изменение состояния от игрока — команда `Cmd(Tick, Nation, Seq, Type, A, B, C)` (`Sim/Commands.cs`): присоединение, стройка, геологи, разведчики, пауза и скорость (сессионные), читы (`CheatGold`, `CheatEra`), ответ на событие (`Choose`). `Game.I.Claim(…)` и другие действия сначала проверяют правило для мгновенного тоста, затем `Game.I.Issue(cmd)` ставит команду в очередь `CommandQueue` на ближайшую границу такта. В одиночной игре граница — «сейчас»: команда исполняется сразу, и на паузе тоже. При исполнении проверка повторяется, команда пишется в журнал (`Game.I.Journal`, строка `Cmd.ToLine()`). Боты отдают те же команды через `Commands.Apply`, но не в журнал: они следуют из состояния. `Replay.Run(мир, начальное состояние, журнал, такт)` воспроизводит партию бит в бит; `GameState.Hash()` — хеш по разделам (время, державы, провинции, постройки, туман, разведчики) для сверки рассинхрона.

**Юниты на ПКМ** (`Core/Game.Units.cs`): ЛКМ по своему отряду разведчиков или роду на карте выбирает его (золотые уголки, `Game.SelectedUnit`, хит-боксы рисует `ScoutOverlay`), ПКМ по провинции отдаёт приказ: разведчики сворачивают туда командой `ScoutMove` (A = `Scout.Id`, B = провинция; отряд сперва доходит до соседней провинции, куда уже шагал, — без рывков), род идёт командой `TribeTo` (ПКМ по своей стоянке — стоп). Пока юнит выбран, под курсором видно, куда он пойдёт: золотой пунктир и флажок или красный крест. Строку разведчиков в панели столицы тоже можно щёлкнуть. Esc снимает выбор; ПКМ во время прицела по-прежнему только отменяет прицел.

**Материалы** (`Nat[n].Materials`, целые): дерево и камень. Дают лесопилка и каменоломня (+2 за цикл), рудник — каменоломня на разведанной жиле меди, олова или железа (ещё +2), столица (+1). Тратятся на постройки (`Rules.BuildMaterials`: от 5 у пастбища до 30 у святилища; лесопилка и каменоломня бесплатны, чтобы из нуля всегда был выход) и на новый город (`Cities.FoundMaterials` = 30). Старт — 40. Остальная руда: золото даёт +1 к налогам провинции, соль — довольство +4. Неразведанная руда не действует.

**Технологии** (`Sim/Techs.cs`, таблица как `Eras.All`): одно дерево от корня «Огонь» (его знают все с начала, `Techs.RootMask`). У каждой — эпоха, ветка (`Lane`) и место в колонке эпохи (`Order`), цена, требования (все нужны), развилка (`Fork`, из одной развилки учится только один путь, навсегда), постройка и эффекты (`TechFx`: предел населения, довольство, материалы каменоломен и рудников, скидка на материалы, влияние городов, исследования, налоги, дальность разведчиков; сумма — `Techs.Sum`). Наука цикла (`Nat[n].ScienceRate`) наполняет запас эпохи и календарь, а в изучаемую технологию идёт `Techs.ResearchRate` = наука + бонусы «исследований» от знаний, поэтому знания ускоряют только изучение и не сжимают партию (темп эпох тот же: Древний мир ≈9 мин, Античность ≈57 мин на «Быстрой»). Цены в таблице: Первобытная 800, Древний мир 2000, развилка 3000; платится вдвое (`Techs.CostPermille` = 2000), так что технология Первобытной идёт ≈2 мин на x3, Древнего мира ≈4–5 мин. Пока ничего не выбрано, очки копятся в `TechPool`, но не больше `Techs.PoolCycles` = 60 циклов исследований (полминуты на x3), остальное пропадает: долгое ожидание не даёт изучить пачку технологий за секунду. Озарения бьют по одному за проверку. Эпоху покидают только с `Techs.Required(e)` технологиями (Первобытная 9 из 15 с огнём, Древний мир 14 из 25). Ветки Первобытной: Огонь → Собирательство → Дикие злаки (ферма); Охота → Острога и сеть (пристань), Приручение (пастбище), Шкуры и иглы; Каменные орудия → Кремень (каменоломня, геологи), Каменный топор (лесопилка) → Плоты; Речь и предания → Духи предков (святилище), Счёт по зарубкам, Совет старейшин. Древний мир продолжает их: Ирригация → Плуг → Севооборот; Колесо → Верховая езда; Медь → Бронза → Рудники; Гончарный круг (амбар) → Обмен (рынок) → Меры и весы; Каменное строительство + Гончарный круг → Кирпич; Календарь → Письменность → Математика; Закон вождя + Кирпич → Первые города → Великая развилка «Храмовое царство / Речная держава / Степной союз»; Жречество → Храмы. Id не двигать (сохранения хранят битовую маску): новые технологии дописываются в конец, форма дерева — `Lane`/`Order`. Боты выбирают сами (`Techs.BotPick`). Команды `Research` и отладочная `CheatTech` (−1 = все); `--era=N` выдаёт всё, что было до эпохи N. Интерфейс — экран `UI/TechScreen.cs` на весь экран (атом или T, Esc закрывает): колонки эпох, ряды веток, линии требований по промежуткам между рядами, рамка развилки. Видна только граница знаний: карточка открывается, когда известно хоть одно её требование, остальное — «???» без линий, дальние эпохи под вуалью. `--techs` открывает экран сразу.

**Кочевье** (`Sim/Nomads.cs`, `GameSetup.Nomad`, из меню включено): после генерации `Nomads.Start` превращает державы в племена на местах будущих столиц (`Nat[n].Camp`), границы, постройки, города и пути снимаются. Племя идёт по суше, провинция за 24 такта (3 с на x3, команда `TribeTo`, −1 = стоп), раз в 16 тактов плодородная земля или река пополняют запасы, бедная и дорога их едят, на нуле уходят люди. Предания (до 3): река, море, холмы, степь, лес, чужой род. `Settle` разводит очаг на стоянке: столица и соседняя свободная земля, половина запасов → материалы, одно предание становится мифом (река/море — предел населения, горцы/лес — материалы, степь — дальность разведчиков, друзья — довольство). Оценка места 0–100: плодородие 40, река 15, море 10, разнообразие земель 20, камень 10, простор 5. Старейшины торопят на 3-й минуте и оседают сами на 5-й; боты — на своём месте за 1–2 минуты. Пока род кочует, наука идёт от шаманов (`Science.Sages`), а проекты столицы ждут. Интерфейс: племя на карте (`ScoutOverlay`), раздел «Род» в панели (`ProvincePanel.Tribe.cs`), у любой разведанной земли — оценка места и «Вести род сюда».

**Только целые числа в Sim.** Население `int`, казна `long` в сотых (`Nat[n].Treasury`), доли в ‰, случайность — целый хеш `SimRng`. Дробные поля мира один раз переводит в целые `WorldFacts`. Линтер детерминизма в SimTests падает на `float/double`, `Math.Sin/Pow/Sqrt…`, `System.Random`, `DateTime`, `Dictionary/HashSet`, Godot и `LocalPlayer` в правилах. Исключение — строка с `// pax-allow` (или файл с `// pax-allow-file: причина`, только для дробей).

**По державам.** `GameState.Nat[n]`: казна, наука, эпоха, проекты столицы, колода событий, туман (`NationFog` есть только у людей, так что 16 карт возможны). `GameState.LocalPlayer` и совместимые свойства (`Gold`, `Fog`, `Explored`, `Met`, `Year`, `QueuePct`…) — только вид для интерфейса.

## Устройство кода (`game/scripts`)
- `Core/`
  - `Game.cs` — синглтон `Game.I`: мир, состояние, часы (`TickPump`), очередь команд, события; `NewGame(GameSetup, мир?)`, `EndGame()`.
  - `Game.Contract.cs` — контракт для интерфейса и фронта: `Setup`, `Nations`, `DateText`, `DateChanged`, `EraIndex`, `EraName`, наука.
  - `GameSetup.cs`, `Session.cs` — настройки партии и передача её из меню; `Nations/NationRoster.cs` — состав держав партии (народ игрока в [0], боты, разведение цветов, флаги ботов).
  - `Data.cs` — таблицы (биомы, державы по умолчанию, религии…).
  - `Noise.cs` — детерминированный шум.
  - `Game.Events.cs` — колода событий на стороне Game: пакет `game/data` читается один раз, окно выбора игрока (`PendingChoice`, `ChooseOption`, `ChoiceChanged`).
  - `Main.cs` — сборка сцены: `Session.Take()`, затем загрузка сохранения (`LoadGame`) или `NewGame(pending?.Setup ?? SetupFromCli(), pending?.World)`.
  - `Settings.cs`, `Audio/Sfx.cs`, `Audio/Music.cs` — автозагрузки (в project.godot раньше `Game`): настройки игрока, звуки, музыка (пока без треков). Звук — см. раздел «Звук» ниже.
  - `Flags/`, `Nations/` — флаги (8 байт, рендер, код `XXXX-XXXX`) и народы (имена, палитра 24 цветов, хранилище «Мои народы»).
  - `Cli.cs` — аргументы командной строки.
- `World/` — генерация мира: рельеф, реки (`RiverGrid`), провинции, цвет рельефа по рампам ART_BIBLE (`TerrainPalette`; поля `TerrMaterial`/`TerrStep` на пиксель — задел под палитру-LUT). Чистый C#, без Godot.
- `Content/` — события из JSON (`ContentDb`, проверка `ContentCheck`), колода `EventRunner`, тексты `EventText`. С Godot связан только `ContentLoader.cs` (читает `res://data`).
- `Sim/` — состояние игры и правила: `GameState` (с `Nat[n]`), `Clock`, `Calendar`, `Eras`, `Science`, `Commands`, `Simulation.Step`, `NationGen`, туман войны, разведчики, боты, события, `Pacing`. Чистый C#, только целые числа, детерминированно (lockstep). С Godot связаны только `GameActions.cs`, `SimDriver.cs`, `SimDebugOverlay.cs`.
- `Map/` — рендер карты на шейдерах (`game/shaders`), камера, пиксельные подписи, спрайты городов по эпохам держав (`Map/Art/SpriteData.g.cs` собирается из `docs/design/concepts/src` скриптом `python game/assets/map/sprites_to_cs.py`), караваны и корабли.
- `UI/` — тёмный пиксельный интерфейс в духе «Mr. President»: общий набор `UI/Kit/PixelKit.cs` + `PixelTheme.cs` (шрифт PixelifySansMrP без сглаживания, рамки 2 px, жёсткие тени), HUD, карточка главы (`ChapterCard`), меню паузы, окно события; `UI/Front/` — главное меню, «Новая игра», «Народ», «Настройки», «Авторы».
- `Dev/` — самопроверка (`--selftest`), сохранения (`--savetest`), замер производительности (`--perf`), QA-прогоны (`--qa`), отчёт о темпе (`--pacing`).

Модули не ссылаются друг на друга напрямую, а общаются через события и методы `Game.I`.

## Облик по эпохам
Интерфейс партии меняет «кожу» вместе с группой эпох (`UI/Theme/EraSkin.cs`, группы как у звука в AUDIO.md): **Костёр** (Первобытная — тёплый камень, кость, охра, фактура каменной крошки), **Глина** (Древний мир, Античность — светлый папирус, терракота, волокна), **Перо** (Средневековье, Возрождение — пергамент, тушь, сургуч, пятна), **Латунь** (пар, индустриальная, атомная — тёмная сталь и латунь, шлифовка), **Сигнал** (информационная и дальше — тёмное стекло, бирюза, строки развёртки). Кожа — это палитра ролей (`Pal`, `PixelKit`: поверхности, линии, чернила, статусы, `OnAc` — текст на акцентной заливке) и фактура плёнки над карточками (`PixelTex.Grain`). Светлые кожи просто меняют концы: `Hi` — всегда самый контрастный цвет к `Card`. `EraSkin.Apply` меняет палитры и сбрасывает темы; `Main` при смене группы эпох пересобирает HUD на том же месте дерева, перенося летопись и выбор провинции, а при новом мире или загрузке — начисто. Меню остаётся графитовым (`EraSkin.Graphite`). Новые цвета в HUD брать только из ролей `Pal`, не `Pal.Hex(...)`, иначе кожа их не перекрасит.

## Звук

**Источники и кожи звука.** Звуки собирает `game/assets/audio/make_assets.py` из CC0-наборов в `audio_src/` (не в git): Kenney (Interface, UI Audio, RPG Audio, Impact, Music Jingles), OwlishMedia «202 More Sound Effects» и «Sound Effects Pack», rubberduck «100 CC0 metal and wood SFX» (opengameart.org), отдельные OGG BigSoundBank (Joseph Sardin) — чтобы игра не звучала одним автором; все записи живые. Скрипт режет тишину, выравнивает уровень по слоям и пишет `sources.json` (каждый файл и его источники). У ключей с материалом — `confirm`, `page`, `pause`/`unpause`, `book_open`/`book_close` — есть кожи по группам эпох (`SoundBank.Skins`, файлы `ui/skin/g<группа>_<ключ>_<n>.ogg`): Костёр — джембе, деревянный блок, камни; Глина — посуда и папирус; Перо — карандаш, пергамент, железная защёлка; Латунь — пишущая машинка, часы, металл; Сигнал — электроника. Наведение, клик и прочие частые звуки не меняются всю игру. Группу выставляет `Main` вместе с кожей интерфейса (`SoundBank.Group`). Скачать исходники: ссылки в `CREDITS_audio.txt` и в шапке скрипта; после пересборки старые OGG перекодируются побайтно иначе — их можно вернуть `git checkout`, если рецепт не менялся.
Закон — `docs/design/AUDIO.md`; сейчас только бесплатный Kenney CC0 (строка в «Авторах»: «Звук: Kenney (kenney.nl), CC0»), атмосферы и музыки пока нет.
- **Шины** (`Core/Audio/AudioBuses.cs`, создаются кодом): Master (лимитер −1 дБ) → Music, Ambience, SFX (−4 дБ) → UI, World, Stingers. Ползунки «Общая», «Музыка», «Эффекты» и «Звук в фоне» (глушить, когда окно не в фокусе) — в `Settings`. Под стингером Music/Ambience приглушаются своими усилителями (−6/−5 дБ, возврат 1,5 с), на паузе Ambience уходит за low-pass 1,2 кГц, Music −4 дБ — ползунков это не касается.
- **Таблица звуков** — `Core/Audio/SoundBank.cs`: ключ → файлы-варианты (`assets/audio/{sfx,ui,world,stingers}`), шина, громкость, разброс тона (±2–4 %) и громкости, минимальный интервал, голоса, ранг. `Sfx` (пул голосов на шину, вариант не повторяется подряд) собирает звуки кадра и играет один — самый важный: щелчок кнопки, открывшей книгу, звучит книгой.
- **Кто звучит.** Кнопки HUD — наведение/щелчок (`UiSounds`, из `Ui.Button`), кнопки меню — через `PixelKit.Sfx`. Игра — `Core/Audio/GameSounds.cs` на событиях `Game.I`: фишка при выборе провинции, тик зума (выше при приближении), вкладка режима карты, тумблер тумана, защёлка паузы и переключатели скоростей (не при меню паузы), команды игрока из `Game.Journal` (присоединение — короткий стингер, стройка, геологи, разведчики), заметки летописи (разведчики вернулись, стройка завершена, новая держава), события колоды — по `EventSounds` (шутки → 8-бит, бедствия, вера, открытия → стингеры, золото → монеты, мировые → «бонг», остальное — страница), окно события — книга. 0,6 с после WorldReady тихо.
- **Стингеры** (`Stingers.cs`): очередь с приоритетами бедствие → эпоха → чудо → религия → открытие → остальное, не чаще раза в 1,6 с, одинаковые сливаются, ждавшие дольше 6 с пропадают; перед фанфарой эпохи 0,4 с тишины. Фанфара — по группе эпох (`stinger_era_2…5`).
- **Файлы** собирает `python game/assets/audio/make_assets.py` из паков в `audio_src/kenney` (вне git): обрезка тишины, склейка составных звуков, общая нормализация, OGG q5; `assets/audio/sources.json` — из каких файлов Kenney сделан каждый. Новый звук: строка в `make_assets.py` → ключ в `SoundBank` → вызов `Sfx.I?.Play("ключ", cause: "…")`.

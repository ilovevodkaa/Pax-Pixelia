# Pax Pixelia — как запустить и разрабатывать

## Что нужно
- **Godot 4.7.1 .NET**: лежит в `tools/godot/Godot_v4.7.1-stable_mono_win64/`. Обычная сборка без .NET не подойдёт, игра на C#.
- **.NET SDK 8** (уже установлен).

## Открыть в редакторе
1. Запусти `tools/godot/Godot_v4.7.1-stable_mono_win64/Godot_v4.7.1-stable_mono_win64.exe`.
2. Выбери «Импорт» → `D:\supergae\game\project.godot`.
3. Нажми F5, чтобы запустить игру. Главная сцена — `scenes/Front.tscn` (титул «PAX PIXELIA» → «Новая игра» → карта); `scenes/Main.tscn` — сама партия.

## Запуск из консоли
```bash
cd game && dotnet build
../tools/godot/Godot_v4.7.1-stable_mono_win64/Godot_v4.7.1-stable_mono_win64_console.exe --path . -- --seed=42
```
Флаги Godot (например `--resolution 1280x720`) ставятся **до** `--`, флаги игры — **после**.

Без флагов открывается главное меню. Если есть любой игровой флаг (`--seed`, `--shot`, `--selftest`…) и нет флагов `--front*`, меню сразу уступает место `Main.tscn`, так что все проверки и скриншоты работают как раньше. Первый раз после клонирования выполни `... --headless --path game --import`, чтобы Godot импортировал шрифт, звуки и картинки.

## Проверки
| Команда | Что делает |
|---|---|
| `... --path game -- --selftest [--selftest-shots=папка]` | прогоняет игру по сценарию (запуск, календарь и эпоха, режимы карты, масштабы и шов, подсказка, панели, присоединение, стройка, геологи, разведчики и туман, пауза и скорость в тактах, смена месяцев, наблюдатель, лидеры, окно события и ответ командой, Esc → меню паузы, «Новый мир», окно 1280×720), печатает `PASS`/`FAIL`, код выхода = число провалов. Без `--noinput`: щит глотает и искусственные клавиши |
| `... --path game -- --front-selftest[=full\|loop]` | главное меню с клавиатуры: обход экранов, стек, Esc, PxConfirm, мир для планеты. `full` — ещё «Новая игра» → `Main.tscn` на мире из меню; `loop` — трижды титул → «Новая игра» → «Народ» → НАЧАТЬ → карточка главы → карта → Esc → пауза → «В главное меню» → титул, и проверка, что узлы, объекты и память не растут |
| `... --path game -- --perf [--perf-seconds=4]` | вертикальная синхронизация выкл.; время генерации по этапам, кадры при ×1/×3/×8 (стоя и в движении), кадры с разведчиками на скорости 5, память; замер правил без карты: мкс на такт и на такт с циклом, худший такт, байт на такт |
| `... --path game -- --pacing [--pacing-hours=60] [--headless]` | партия одних ботов на текущем мире, три пресета параллельно: когда лидер входит в каждую эпоху (дата, реальные часы на x3, дней за такт), затем выход (~1 мин) |
| `... --path game -- --inputtest` | настоящие события мыши и клавиатуры: наведение, колесо, перетаскивание, щелчок, Esc, +/−, смена размера окна, прыжок камеры |
| `... --headless --audio-driver Dummy --path game -- --sfxprobe [--sfxlog]` | звук: каждое событие по разу на паузе (фишка, зум по тону, панорама без звука, режимы, туман, пауза/скорость и Пробел, золото, присоединение, отказ, стройка, геологи, разведчики, заметки, события колоды каждого класса, окно выбора, фанфара эпохи после вдоха тишины, наведение и нажатие в HUD, меню паузы без защёлки) — ровно ожидаемые звуки; затем 20 с на скорости 5 с разведчиками, панорамой и зумом: ни один звук не чаще своего интервала, не больше 4 в секунду. Код выхода = число провалов |
| `cd tests/WorldGenTests && dotnet run -c Release` | генератор мира: инварианты, качество рек (без гребёнок и прямых), золотые хеши сидов 1337/42/777, детерминизм по числу потоков, бюджет 600 мс. После намеренного изменения — посмотреть `--png=папка [--crops=x,y;…]` и перезапустить с `--bless` |
| `cd tests/ContentTests && dotnet run -c Release [seed=N] [pace=480\|1000\|1600] [verbose]` | проверка game/data (ключи, тон, шутки со справкой) и сухой прогон колоды событий на всю партию: событие раз в ~67 с, детерминизм |
| `cd tests/SimTests && dotnet run -c Release [-- pacing\|bench]` | правила без Godot: линтер детерминизма, часы и календарь, туман, разведчики по тактам, команды, экономика, 1400 циклов, детерминизм при любой нарезке тактов и частоте кадров, реплей журнала (и для двух людей), состав держав, колода событий (окно выбора и команда `Choose`), быстрый pacing. `pacing` — полный отчёт по трём пресетам (с колодой событий), `bench` — только замер правил |

## Время, календарь и команды
**Один такт — одни часы.** Все правила считают такты постоянной реальной длины (`Sim/Clock.cs`). Скорости 1–5 = **2 / 4 / 8 / 16 / 40 тактов в секунду**. Реальное время превращается в такты целым счётчиком (`Sim/TickPump.cs`): после любого отрезка времени тактов ровно ⌊мкс × тактов в секунду / 10⁶⌋, как бы он ни был нарезан на кадры; кадр длиннее 0,25 с обрезается. Второго счётчика нет.
- Каждый такт: шаг разведчиков (16 из 40 подшагов на провинцию: 2,5 такта = 0,31 с на x3). Каждый 4-й такт — **цикл правил** (0,5 с на x3, как бывший «год»): налоги и содержание, рост населения, довольство, наука и эпохи, проекты столиц, боты, колода событий.
- **Наука** — запас очков прогресса у каждой державы (`Nat[n].Progress`): мудрецы 4 + земли до 4 (1 за 5 провинций) + святилища до 2 (1 за 2), +25% тем, кто отстал от эпохи лидера. Эпоха державы — по таблице порогов `Sim/Eras.cs` (11 эпох, стоимость каждой × `PacePermille` / 1000). Будущее дерево технологий будет кормить тот же запас.
- **Календарь выводится из прогресса лидера**, а не из прошедшего времени (`Sim/Calendar.cs`): таблица 11×17 в `Day256` (дни × 256 от 1 января 4000 до н. э.). Каждая эпоха начинается ровно 1 января своего года на любом пресете: Древний мир 3090 до н. э., Античность 880 до н. э., Средневековье 620, Возрождение 1410, Пар 1730, Индустриальная 1855, Атомная 1930, Информационная 1980, Космическая 2025, Будущее 2070. Дата плавно догоняет цель за цикл. На x3 это ≈ месяц за такт в Первобытную, несколько дней в Средневековье и доли дня в новое время. Года 0 нет.
- Текст даты (`Game.I.DateText`): «март 3200 до н. э.», пока такт длиннее 15 дней, потом «12 марта 1893» (до 1000 г. — «1 мая 620 н. э.»).
- Проверено `pacing`: Быстрая 12,0 ч · Обычная 25,0 ч · Эпическая 40,0 ч на x3 до Будущего, эпохи в свои годы.

**События** — данные в `game/data` (151 событие: летопись, выбор, пасхалки, нити, мировые), колода `Content/EventRunner` (чистый C#, целые числа). `Sim/SimEvents.cs` привязывает её к партии: у каждой державы своя память, колода сдаёт раз в 90–180 циклов (45–90 с на x3), выбор — раз в 360–480. Боты отвечают по весам ИИ, игроку открывается окно (`UI/EventWindow.cs`), ответ — команда `Choose`; без ответа к сроку берётся первый вариант. Эффекты — казна, довольство, население в ‰, наука; остальные показатели (стабильность, культура…) пока нейтральны, и события, которым нужны несуществующие системы, в колоду не попадают. Итог пишется в летопись. `GameSetup.JokePercent` — «Летописец» (0/100/200).

**Всё — приказ.** Любое изменение состояния от игрока — команда `Cmd(Tick, Nation, Seq, Type, A, B, C)` (`Sim/Commands.cs`): присоединение, стройка, геологи, разведчики, пауза и скорость (сессионные), читы (`CheatGold`, `CheatEra`), ответ на событие (`Choose`). `Game.I.Claim(…)` и другие действия сначала проверяют правило для мгновенного тоста, затем `Game.I.Issue(cmd)` ставит команду в очередь `CommandQueue` на ближайшую границу такта. В одиночной игре граница — «сейчас»: команда исполняется сразу, и на паузе тоже. При исполнении проверка повторяется, команда пишется в журнал (`Game.I.Journal`, строка `Cmd.ToLine()`). Боты отдают те же команды через `Commands.Apply`, но не в журнал: они следуют из состояния. `Replay.Run(мир, начальное состояние, журнал, такт)` воспроизводит партию бит в бит; `GameState.Hash()` — хеш по разделам (время, державы, провинции, постройки, туман, разведчики) для сверки рассинхрона.

**Только целые числа в Sim.** Население `int`, казна `long` в сотых (`Nat[n].Treasury`), доли в ‰, случайность — целый хеш `SimRng`. Дробные поля мира один раз переводит в целые `WorldFacts`. Линтер детерминизма в SimTests падает на `float/double`, `Math.Sin/Pow/Sqrt…`, `System.Random`, `DateTime`, `Dictionary/HashSet`, Godot и `LocalPlayer` в правилах. Исключение — строка с `// pax-allow` (или файл с `// pax-allow-file: причина`, только для дробей).

**По державам.** `GameState.Nat[n]`: казна, наука, эпоха, проекты столицы, колода событий, туман (`NationFog` есть только у людей, так что 16 карт возможны). `GameState.LocalPlayer` и совместимые свойства (`Gold`, `Fog`, `Explored`, `Met`, `Year`, `QueuePct`…) — только вид для интерфейса.

## Устройство кода (`game/scripts`)
- `Core/`
  - `Game.cs` — синглтон `Game.I`: мир, состояние, часы (`TickPump`), очередь команд, события; `NewGame(GameSetup, мир?)`, `EndGame()`.
  - `Game.Contract.cs` — контракт для интерфейса и фронта: `Setup`, `Nations`, `DateText`, `DateChanged`, `EraIndex`, `EraName`, наука.
  - `GameSetup.cs`, `Session.cs` — настройки партии и передача её из меню; `Nations/NationRoster.cs` — состав держав партии (народ игрока в [0], боты, разведение цветов, флаги ботов).
  - `Data.cs` — таблицы (биомы, державы по умолчанию, религии…).
  - `Noise.cs` — детерминированный шум.
  - `Game.Events.cs` — колода событий на стороне Game: пакет `game/data` читается один раз, окно выбора игрока (`PendingChoice`, `ChooseOption`, `ChoiceChanged`).
  - `Main.cs` — сборка сцены: `Session.Take()`, затем `NewGame(pending?.Setup ?? SetupFromCli(), pending?.World)`.
  - `Settings.cs`, `Audio/Sfx.cs`, `Audio/Music.cs` — автозагрузки (в project.godot раньше `Game`): настройки игрока, звуки, музыка (пока без треков). Звук — см. раздел «Звук» ниже.
  - `Flags/`, `Nations/` — флаги (8 байт, рендер, код `XXXX-XXXX`) и народы (имена, палитра 24 цветов, хранилище «Мои народы»).
  - `Cli.cs` — аргументы командной строки.
- `World/` — генерация мира: рельеф, реки (`RiverGrid`), провинции, цвет рельефа по рампам ART_BIBLE (`TerrainPalette`; поля `TerrMaterial`/`TerrStep` на пиксель — задел под палитру-LUT). Чистый C#, без Godot.
- `Content/` — события из JSON (`ContentDb`, проверка `ContentCheck`), колода `EventRunner`, тексты `EventText`. С Godot связан только `ContentLoader.cs` (читает `res://data`).
- `Sim/` — состояние игры и правила: `GameState` (с `Nat[n]`), `Clock`, `Calendar`, `Eras`, `Science`, `Commands`, `Simulation.Step`, `NationGen`, туман войны, разведчики, боты, события, `Pacing`. Чистый C#, только целые числа, детерминированно (lockstep). С Godot связаны только `GameActions.cs`, `SimDriver.cs`, `SimDebugOverlay.cs`.
- `Map/` — рендер карты на шейдерах (`game/shaders`), камера, пиксельные подписи, спрайты городов по эпохам держав (`Map/Art/SpriteData.g.cs` собирается из `docs/design/concepts/src` скриптом `python game/assets/map/sprites_to_cs.py`), караваны и корабли.
- `UI/` — тёмный пиксельный интерфейс в духе «Mr. President»: общий набор `UI/Kit/PixelKit.cs` + `PixelTheme.cs` (шрифт PixelifySansMrP без сглаживания, рамки 2 px, жёсткие тени), HUD, карточка главы (`ChapterCard`), меню паузы, окно события; `UI/Front/` — главное меню, «Новая игра», «Народ», «Настройки», «Авторы».
- `Dev/` — самопроверка (`--selftest`), замер производительности (`--perf`), QA-прогоны (`--qa`), отчёт о темпе (`--pacing`).

Модули не ссылаются друг на друга напрямую, а общаются через события и методы `Game.I`.

## Звук
Закон — `docs/design/AUDIO.md`; сейчас только бесплатный Kenney CC0 (строка в «Авторах»: «Звук: Kenney (kenney.nl), CC0»), атмосферы и музыки пока нет.
- **Шины** (`Core/Audio/AudioBuses.cs`, создаются кодом): Master (лимитер −1 дБ) → Music, Ambience, SFX (−4 дБ) → UI, World, Stingers. Ползунки «Общая», «Музыка», «Эффекты» и «Звук в фоне» (глушить, когда окно не в фокусе) — в `Settings`. Под стингером Music/Ambience приглушаются своими усилителями (−6/−5 дБ, возврат 1,5 с), на паузе Ambience уходит за low-pass 1,2 кГц, Music −4 дБ — ползунков это не касается.
- **Таблица звуков** — `Core/Audio/SoundBank.cs`: ключ → файлы-варианты (`assets/audio/{sfx,ui,world,stingers}`), шина, громкость, разброс тона (±2–4 %) и громкости, минимальный интервал, голоса, ранг. `Sfx` (пул голосов на шину, вариант не повторяется подряд) собирает звуки кадра и играет один — самый важный: щелчок кнопки, открывшей книгу, звучит книгой.
- **Кто звучит.** Кнопки HUD — наведение/щелчок (`UiSounds`, из `Ui.Button`), кнопки меню — через `PixelKit.Sfx`. Игра — `Core/Audio/GameSounds.cs` на событиях `Game.I`: фишка при выборе провинции, тик зума (выше при приближении), вкладка режима карты, тумблер тумана, защёлка паузы и переключатели скоростей (не при меню паузы), команды игрока из `Game.Journal` (присоединение — короткий стингер, стройка, геологи, разведчики), заметки летописи (разведчики вернулись, стройка завершена, новая держава), события колоды — по `EventSounds` (шутки → 8-бит, бедствия, вера, открытия → стингеры, золото → монеты, мировые → «бонг», остальное — страница), окно события — книга. 0,6 с после WorldReady тихо.
- **Стингеры** (`Stingers.cs`): очередь с приоритетами бедствие → эпоха → чудо → религия → открытие → остальное, не чаще раза в 1,6 с, одинаковые сливаются, ждавшие дольше 6 с пропадают; перед фанфарой эпохи 0,4 с тишины. Фанфара — по группе эпох (`stinger_era_2…5`).
- **Файлы** собирает `python game/assets/audio/make_assets.py` из паков в `audio_src/kenney` (вне git): обрезка тишины, склейка составных звуков, общая нормализация, OGG q5; `assets/audio/sources.json` — из каких файлов Kenney сделан каждый. Новый звук: строка в `make_assets.py` → ключ в `SoundBank` → вызов `Sfx.I?.Play("ключ", cause: "…")`.

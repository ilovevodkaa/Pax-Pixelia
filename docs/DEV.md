# Pax Pixelia — как запустить и разрабатывать

## Что нужно
- **Godot 4.7.1 .NET**: лежит в `tools/godot/Godot_v4.7.1-stable_mono_win64/`. Обычная сборка без .NET не подойдёт, игра на C#.
- **.NET SDK 8** (уже установлен).

## Открыть в редакторе
1. Запусти `tools/godot/Godot_v4.7.1-stable_mono_win64/Godot_v4.7.1-stable_mono_win64.exe`.
2. Выбери «Импорт» → `D:\supergae\game\project.godot`.
3. Нажми F5, чтобы запустить игру.

## Запуск из консоли
```bash
cd game && dotnet build
../tools/godot/Godot_v4.7.1-stable_mono_win64/Godot_v4.7.1-stable_mono_win64_console.exe --path . -- --seed=42
```
Флаги Godot (например `--resolution 1280x720`) ставятся **до** `--`, флаги игры — **после**.

## Проверки
| Команда | Что делает |
|---|---|
| `... --path game -- --selftest [--selftest-shots=папка]` | прогоняет игру по сценарию (запуск, режимы карты, масштабы и шов, подсказка, панели, присоединение, стройка, геологи, разведчики и туман, пауза и скорость, наблюдатель, лидеры, «Новый мир», окно 1280×720), печатает `PASS`/`FAIL`, код выхода = число провалов |
| `... --path game -- --perf [--perf-seconds=4]` | вертикальная синхронизация выкл.; время генерации по этапам, кадры при ×1/×3/×8 (стоя и в движении), кадры с разведчиками на скорости 5, память |
| `... --path game -- --inputtest` | настоящие события мыши и клавиатуры: наведение, колесо, перетаскивание, щелчок, Esc, +/−, смена размера окна, прыжок камеры |
| `cd tests/WorldGenTests && dotnet run -c Release` | генератор мира сверяется с HTML-прототипом бит в бит (сиды 1337, 42, 777), инварианты, детерминизм |
| `cd tests/SimTests && dotnet run -c Release` | правила без Godot: туман, разведчики, присоединение, стройка, экономика, 1400 лет событий, детерминизм |

## Флаги игры (после `--`)
**Общие** (`Core/Main.cs`)
| Флаг | Что делает |
|---|---|
| `--seed=N` | зерно мира (по умолчанию 1337) |
| `--mode=ter\|pol\|rel\|trd\|fer` | режим карты |
| `--nofog` | режим наблюдателя, без тумана войны |
| `--shot=путь.png --shot-delay=2 --quit` | скриншот и выход |

**Карта** (`Map/MapDebug.cs`)
| Флаг | Что делает |
|---|---|
| `--zoom=N`, `--cam=x,y` | начальный масштаб (1…8) и центр вида в пикселях мира |
| `--select=capital\|x,y\|id`, `--hover=…` | выбрать / навести провинцию |
| `--nosmooth` | без плавного масштабирования и перелётов камеры |
| `--regen=SEED` | сразу заменить мир (проверка «Нового мира») |
| `--mapstats`, `--pan=px/s`, `--zoomcycle` | счётчик кадров раз в секунду, автопрокрутка, качание масштаба |

**Симуляция** (`Sim/SimDriver.cs`)
| Флаг | Что делает |
|---|---|
| `--speed=1..5`, `--pause` | скорость, старт на паузе |
| `--autoscout[=N]`, `--scout-to=P\|x,y` | отправить разведчиков: авто или к провинции |
| `--years=N`, `--autoclaim=N` | промотать N лет, присоединить N плодородных соседей |
| `--simlog`, `--simdebug[ --simdebug-zoom=Z]` | летопись и тосты в консоль; слой отладки тумана |

**Интерфейс** (`UI/UiDebug.cs`)
| Флаг | Что делает |
|---|---|
| `--select=capital\|own\|foreign\|foreigncap\|claim\|unowned\|sea\|fog\|fogsea\|stale` | открыть нужный вариант панели |
| `--hover=<то же> [--mouse=x,y]` | подсказка провинции в заданной точке |
| `--tipui=gold\|sci\|pop\|stab\|infl\|clock\|pause\|pips\|session\|nation\|screen\|trophy\|fog\|mode\|regen\|zoom\|minimap` | показать подсказку элемента |
| `--lead`, `--build`, `--targeting`, `--notes`, `--loading`, `--icons`, `--noselect` | открыть таблицу лидеров / меню стройки / выбор цели разведчиков / 3 записи летописи / экран загрузки / лист иконок; не выбирать столицу |
| `--toast[=текст] [--toastkind=pick\|err]`, `--scroll=px`, `--session=минуты` | тост, прокрутка панели, таймер сессии |
| `--clicks=x,y@сек;…`, `--moves=x,y@сек`, `--keys=space@сек;5@сек;esc@сек` | искусственный ввод через настоящий конвейер интерфейса |

## Устройство кода (`game/scripts`)
- `Core/`
  - `Game.cs` — синглтон `Game.I`: мир, состояние, часы, события.
  - `Data.cs` — таблицы (биомы, державы, религии…).
  - `Noise.cs` — детерминированный шум.
  - `Main.cs` — сборка сцены.
  - `Cli.cs` — аргументы командной строки.
- `World/` — генерация мира: рельеф, реки, провинции (`WorldData`, `WorldGen`). Чистый C#, без Godot.
- `Sim/` — состояние игры и правила: `GameState`, `NationGen`, туман войны, разведчики, действия, события. Чистый C#, детерминированно (для будущего lockstep-мультиплеера). С Godot связаны только `GameActions.cs`, `SimDriver.cs`, `SimDebugOverlay.cs`, `Simulation.cs`.
- `Map/` — рендер карты на шейдерах (`game/shaders`), камера, подписи, спрайты.
- `UI/` — интерфейс «Мрамор и графит»: тема, панели, миникарта.
- `Dev/` — самопроверка (`--selftest`) и замер производительности (`--perf`).

Модули не ссылаются друг на друга напрямую, а общаются через события и методы `Game.I`.

## Иконки интерфейса
`game/assets/ui/*.svg` читаются как исходные SVG и растрируются ровно в нужном размере. Их импорт стоит в режиме «Keep File (exported as is)» (`importer="keep"` в `.svg.import`): Godot не превращает их в текстуры и кладёт в экспорт как есть. Новую иконку импортируй так же.

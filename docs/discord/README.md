# Статус в Discord

Игра показывает друзьям в Discord «Играет в Pax Pixelia»:

- первая строка — «👑 Держава · Эпоха» (в блице «⚡ Блиц недели · Держава»), в меню «🏠 В главном меню», при создании
  мира «🌋 Творит новый мир» и шаг генерации;
- вторая строка каждые 20 с сменяется: чудо, наука, стройка в столице, разведчики, жители и провинции, слава, место в
  таблице, дата; у кочевого племени — путь, припасы, легенды; в блице — остаток времени и очки;
- большая картинка — город эпохи (`scene0` … `scene10`), подсказка — путь до следующей эпохи;
- маленькая — значок текущей строки (`act_*`), на паузе `act_pause`;
- время в партии и кнопка «Pax Pixelia на GitHub» (её видят другие, не сам игрок).

Код: `game/scripts/Core/Discord/` — `DiscordIpc` (локальный канал `discord-ipc-N` клиента Discord), `PresenceCard`
(что написать), `DiscordPresence` (автозагрузка). Выключается в Настройки → Интерфейс → «Статус в Discord». Флаг
`--discord` включает статус и при запуске с флагами и печатает каждую карточку в лог.

Приложение Discord: https://discord.com/developers/applications → **Pax Pixelia**; его Application ID записан в
`DiscordPresence.ClientId`. Картинки этой папки (`python docs/discord/make_art.py` из корня репозитория) загружены туда
в Rich Presence → Art Assets под своими именами: `logo`, `scene0…10`, `act_*`, `era0…10` (значки эпох, сейчас не
используются).
